# Логотип Amazake

Японская чаша-тяван на тёмно-синей плитке. В неё окунается рисовое зерно, разрезанное вдоль на три
параллельные дорожки — потоки ядра; центральная янтарная дорожка — главный поток. Амадзаке (甘酒) —
сладкий японский напиток из риса.

| Цвет | HEX |
|---|---|
| Синий (плитка) | `#1F2B4D` |
| Рисовый крем (чаша, дорожки) | `#F6ECDC` |
| Янтарь (главная дорожка, ножка) | `#E9A23B` |
| Напиток | `#E2CFAE` |
